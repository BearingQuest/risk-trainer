Read these with care

  • Learners chose to try these scenarios, so they aren't a representative sample.
  • The totals include the site owner's own test attempts.
  • It's a rolling window of about six months: older months drop off.
  • Only the current version of each scenario is counted. A new version starts from zero.
  • This is a learning tool, not research.

Totals only. A scenario shows nothing until it has at least {{ min_sample }} attempts in the window, and the site-wide totals count only those scenarios. Percentages are rounded to whole numbers, so they may not add up to 100. See Privacy.
